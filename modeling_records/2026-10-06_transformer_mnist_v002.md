## 假设、变量与公式

所有 28 个行位置共享同一套输入投影参数。输入维度 D=28 来自每行的像素数；`d_model=32` 是沿用 v001 的教学超参数，未证明是最佳宽度。该宽度可与计划的 4 个注意力头配合，但本轮未实现头的拆分。

```text
X:         (28,28)
W_in:      (28,32)
b_in:      (32,)
embedding = X @ W_in + b_in: (28,32)
```

偏置广播到全部行。每个输出特征是该行 28 个像素的加权组合加偏置，32 维指特征宽度，图片的行数或像素分辨率没有增加。参数共 `28×32+32=928` 个。

初始化采用 CuPy 随机种子 42、标准正态权重乘以 0.1，偏置全零。0.1 为本例的初始化尺度，不称作标准或最佳方案。参数尚未训练，因此这些特征尚未经过任务学习。

## 本步代码

把以下片段直接追加在用户当前数据准备代码后面，不重复导入或重写第 1 步。

```python
# ==================================================
# 输入投影参数初始化
# ==================================================

cp.random.seed(42)

input_size = 28
d_model = 32

W_in = cp.random.randn(input_size, d_model).astype(cp.float32) * 0.1
b_in = cp.zeros(d_model, dtype=cp.float32)

print("W_in:", W_in.shape)
print("b_in:", b_in.shape)


# ==================================================
# 将每行的 28 个像素映射成 32 个特征
# ==================================================

X = x_train[0]
embedding = cp.dot(X, W_in) + b_in

print("X:", X.shape)
print("embedding:", embedding.shape)
print("一行映射后的特征:", embedding[0].shape)
print("W_in 的实际设备:", W_in.device)
print("embedding 的实际设备:", embedding.device)
```
