```python
# ==================================================
# 参数初始化
# ==================================================

np.random.seed(42)

W1 = np.random.randn(784, 64) * 0.01
b1 = np.zeros(64)

W2 = np.random.randn(64, 10) * 0.01
b2 = np.zeros(10)

print("W1:", W1.shape)
print("b1:", b1.shape)
print("W2:", W2.shape)
print("b2:", b2.shape)
```

W1 的每一列保存一个隐藏神经元接收 784 个输入的权重；b1 为 64 个隐藏神经元各提供一个偏置。W2 的每一列保存一个输出神经元接收 64 个隐藏层输出的权重；b2 为 10 个输出神经元各提供一个偏置。

单样本 x 的形状为 (784,)，x @ W1 的形状为 (64,)，再加 b1；下一层以 64 个隐藏层输出乘 W2 得到 10 个分数，再加 b2。这里的 @ 用于说明维度，后续实际代码沿用 np.dot。尚未执行前向传播。

np.random.seed(42) 便于在相同环境与调用顺序下复现初始化；randn 生成标准正态随机数，乘以 0.01 将标准差缩小为 0.01，数值不保证全部位于 ±0.01 内。随机权重避免隐藏神经元以相同参数开始学习；偏置允许初始化为零。0.01 是承接 cnn_mnist.py 风格的教学选择，尚未证明它最适合该网络。
