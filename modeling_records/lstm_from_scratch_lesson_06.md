# 手写 LSTM 第 6 步：输出层反向传播

日期：2026-10-06；版本：v006。
前置：用户已保存 28 步前向、one-hot 与 MSE，output 为 (10,)，最后 h 为 (64,)。本步只计算分类层参数和最终隐藏状态的梯度。

## 追加代码

```python
# ==================================================
# 输出层反向传播
# ==================================================

# 损失对十个输出分数的梯度
d_output = 2 * (output - target) / output_size

# 分类层参数的梯度
d_W_y = np.outer(h, d_output)
d_b_y = d_output.copy()

# 分类层传回最后一个时间步 h 的梯度
d_h = np.dot(d_output, W_y.T)

print("d_output:", d_output.shape)
print("d_W_y:", d_W_y.shape)
print("d_b_y:", d_b_y.shape)
print("d_h:", d_h.shape)

print("d_output 的值:", d_output)
print("d_h 前 5 个值:", d_h[:5])
```

## 梯度含义

此前 L=mean((output-target)**2)，对十个输出分量平均。对应 d_output=2*(output-target)/output_size，其中 output_size=10，没有额外 0.5 系数。

分类线性层 output[k]=sum_j h[j]*W_y[j,k]+b_y[k]。
由链式法则：
- d_W_y[j,k]=h[j]*d_output[k]，用两个向量的外积得到 (64,10)；
- d_b_y[k]=d_output[k]，copy 生成独立数组，数值相同；
- d_h[j]=sum_k d_output[k]*W_y[j,k]，因此 d_output @ W_y.T 得到 (64,)。

d_h 是损失对最后一步隐藏状态的导数，描述其各分量变化时损失的局部敏感程度。它不是 h 自身的变化量，不应拿它直接更新 h。后续会通过状态递推和各个门的计算继续传递，最终得到共享门参数的梯度。可训练参数在全部所需梯度算完后再做优化更新。

## 实际验证与范围

Python 3.13.15、NumPy 2.5.3、CPU float64，项目解释器独立运行用户实际初始化/前向/损失段与本课片段。未修改用户主 Python 文件，所有可训练参数和 h 均保持不变。
中央差分步长 1e-6，容差 1e-8；检查 d_output 全部 10 项、d_b_y 全部 10 项、最终 h 的 64 项、W_y 抽样 6 项。最大绝对误差分别约 6.66e-12、6.66e-12、2.09e-11、8.66e-12，均通过。
