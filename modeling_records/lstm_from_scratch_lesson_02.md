# 手写 LSTM 第 2 步：初始化参数与状态

日期：2026-10-05；版本：v002。追加在用户已完成的数据准备代码之后。使用 NumPy 基础数组运算；本步尚不执行 LSTM 前向、反向或训练。

## 本步代码

```python
# ==================================================
# LSTM 参数初始化
# ==================================================

np.random.seed(42)

input_size = 28       # 每一步输入一行：28 个像素
hidden_size = 64      # 隐藏状态和细胞状态的长度
output_size = 10     # 数字类别：0～9
combined_size = input_size + hidden_size

# 遗忘门：控制旧记忆保留多少
W_f = np.random.randn(combined_size, hidden_size) * 0.1
b_f = np.ones(hidden_size)

# 输入门：控制新信息写入多少
W_i = np.random.randn(combined_size, hidden_size) * 0.1
b_i = np.zeros(hidden_size)

# 候选记忆：准备写入的新内容
W_g = np.random.randn(combined_size, hidden_size) * 0.1
b_g = np.zeros(hidden_size)

# 输出门：控制记忆向隐藏状态输出多少
W_o = np.random.randn(combined_size, hidden_size) * 0.1
b_o = np.zeros(hidden_size)

# 分类层：最后一步的隐藏状态映射到 10 类
W_y = np.random.randn(hidden_size, output_size) * 0.1
b_y = np.zeros(output_size)

# 一张图片开始时的状态
h = np.zeros(hidden_size)
c = np.zeros(hidden_size)

print("W_f:", W_f.shape)
print("W_y:", W_y.shape)
print("h:", h.shape)
print("c:", c.shape)
```

## 尺寸与含义

每张图片沿行扫描 28 步，每一步 x_t 是长度 28 的向量。隐藏宽度 64 是本次教学设置，可以调整，不是图片自动决定的。后续将按顺序拼接 q_t=[x_t,h_(t-1)]，因此输入门控计算的向量长度为 28+64=92。

| 参数或状态 | 尺寸 | 含义 |
| --- | --- | --- |
| W_f、W_i、W_g、W_o | (92,64) | 将当前行与上一步隐藏状态共同映射到 64 个分量 |
| b_f、b_i、b_g、b_o | (64,) | 对应偏置 |
| W_y | (64,10) | 末步隐藏状态到十类分数 |
| b_y | (10,) | 分类层偏置 |
| h、c | (64,) | 每步变化的状态，不属于可训练参数 |

f/i/o 分别是遗忘门、输入门和输出门；g 是候选记忆，因此是三个门加一组候选记忆计算。
c 是内部记忆，后续以“保留旧记忆 + 写入新内容”更新。h 是由当前记忆与输出门得到的隐藏状态，会参与下一步计算，最后一步也用于分类。这不是保证所有信息都能被记住的承诺。

四组权重矩阵不是四份网络在分别识别图片，而是同一 LSTM 单元里控制状态更新的不同参数。以后同一组参数会在 28 个时间步重复使用。

## 初始化选择（教学判断）

seed=42 固定随机初始化，便于重现。正态权重乘 0.1 表示初始分布标准差为 0.1，并非把每个权重都设为 0.1。这是本次起点；门控接收 92 个输入，1/sqrt(92) 约为 0.104，可作尺度粗略参考，不能据此断言初始化最优。此前 DNN 的 0.01 是另一种选择，不是所有模型必须采用的常数。

遗忘门偏置设为 1，其余偏置置零。在其他线性贡献接近零时，遗忘门值接近 sigmoid(1)=0.731，而零偏置对应 0.5；此选择增加初始保留旧记忆的倾向，不表示完整保留，也不保证 28 步都能记住。第一步 c 初值为零，仍要靠候选记忆与输入门写入信息。

h、c 在一张图片开始前置零，处理同一图片的下一行时传递更新后的状态。以后写图片循环时，应把这两句放在每张图片开始处；不要在每一行都重新清零，也不要把上一张独立图片的状态直接带入下一张。
