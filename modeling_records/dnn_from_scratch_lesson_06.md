在输出层反向传播之后追加以下代码。保持全部梯度算完之后再更新参数；助手未修改用户 Python 文件。

```python
# ==================================================
# 隐藏层反向传播
# ==================================================

d_a1 = np.dot(d_output, W2.T)

d_z1 = d_a1 * (z1 > 0)

d_W1 = np.outer(x, d_z1)
d_b1 = d_z1

print("d_a1:", d_a1.shape)
print("d_z1:", d_z1.shape)
print("d_W1:", d_W1.shape)
print("d_b1:", d_b1.shape)
```

从输出层传回隐藏层的公式：d_a1[j]=Σ_k d_output[k]W2[j,k]。W2 为 (64,10)，W2.T 为 (10,64)，因此长度 10 的 d_output 与 W2.T 做 np.dot 得到长度 64 的 d_a1。

ReLU 正数区域导数为 1，负数区域导数为 0，零点不可导，本代码约定零点取 0。z1>0 产生布尔掩码，乘法中 True 对应 1、False 对应 0；d_z1=d_a1*(z1>0)。这样当前样本中 z1 不大于零的位置不会把梯度传回 W1。

隐藏层加权和 z1[j]=Σ_i x[i]W1[i,j]+b1[j]，所以 d_W1[i,j]=x[i]d_z1[j]；d_b1[j]=d_z1[j]。np.outer 生成 (784,64) 的外积，与 W1 形状一致。

用户现有代码将 np.outer 注释为“矩阵乘法”；更精确的术语是两个向量的外积，每一对元素相乘，不做求和。建议用户自行将注释改为“外积，生成权重梯度”。

本步实际中心差分检验首个样本 64 个抽样 W1 元素与全部 64 个 b1 元素，覆盖 ReLU 激活和未激活神经元；通过 1e-7 最大绝对误差阈值。未训练网络。下一步统一更新 W1、b1、W2、b2，再对同一图片重算损失。
