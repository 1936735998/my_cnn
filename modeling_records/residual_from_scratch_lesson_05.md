```python
# ==================================================
# 残差分支第二层：W3、b3
# ==================================================

d_W3 = np.outer(u, d_F_h)
d_b3 = d_F_h

d_u = np.dot(d_F_h, W3.T)


# ==================================================
# 经过残差分支中的 ReLU
# ==================================================

d_z2 = d_u * (z2 > 0)


# ==================================================
# 残差分支第一层：W2、b2
# ==================================================

d_W2 = np.outer(h, d_z2)
d_b2 = d_z2

d_h_main = np.dot(d_z2, W2.T)


# ==================================================
# 汇总两条路径对 h 的梯度
# ==================================================

d_h = d_h_skip + d_h_main

print("d_W3:", d_W3.shape, "d_b3:", d_b3.shape)
print("d_W2:", d_W2.shape, "d_b2:", d_b2.shape)
print("d_h_main:", d_h_main.shape)
print("d_h:", d_h.shape)
```

前向分支 F_h=uW3+b3，因此 d_W3=u 外积 d_F_h，d_b3=d_F_h，d_u=d_F_h W3^T。W3 后是线性输出，此处不加 ReLU 掩码；分支内的 ReLU 是 u=ReLU(z2)，所以 d_z2=d_u*(z2>0)。第一分支层 z2=hW2+b2，于是 d_W2=h 外积 d_z2，d_b2=d_z2，d_h_main=d_z2 W2^T。

h 同时影响直接路径和残差分支，完整梯度须相加：d_h=d_h_skip+d_h_main。上一段的复制发生在相加节点的局部输入上，这里的相加发生在共享输入 h 的两条路径贡献汇总处；二者对应不同计算节点。

实际中心差分检查全部 4096 个 W3、64 个 b3、4096 个 W2、64 个 b2、64 个 h 总梯度，最大绝对误差均低于 1e-7。检查 h 时同时重算 F(h) 和直接路径，验证的是完整 d_h。尚未计算输入映射层 W1/b1，也未更新参数或训练。
