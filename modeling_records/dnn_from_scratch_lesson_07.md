本步进行一次真实的单样本参数更新并重算损失。读取用户当前保存文件，发现仍停在输出层反向传播，尚未保存 v006 隐藏层梯度；因此本段先包含其四行，避免未定义变量。用户若已经加入上一段，只需接续参数更新部分。助手没有改写用户 Python 文件。

```python
# ==================================================
# 隐藏层反向传播（上一段尚未添加时，先补齐）
# ==================================================

d_a1 = np.dot(d_output, W2.T)
d_z1 = d_a1 * (z1 > 0)

d_W1 = np.outer(x, d_z1)
d_b1 = d_z1


# ==================================================
# 参数更新
# ==================================================

learning_rate = 0.01
loss_before = loss

W1 = W1 - learning_rate * d_W1
b1 = b1 - learning_rate * d_b1

W2 = W2 - learning_rate * d_W2
b2 = b2 - learning_rate * d_b2


# ==================================================
# 更新后重新计算损失
# ==================================================

z1_new = np.dot(x, W1) + b1
a1_new = relu(z1_new)
output_new = np.dot(a1_new, W2) + b2

loss_after = np.mean(
    (output_new - target) ** 2
)

import sys

print("Python:", sys.version.split()[0])
print("计算框架: NumPy", np.__version__)
print("参数计算设备: CPU（NumPy 数组）")

print("更新前损失:", loss_before)
print("更新后损失:", loss_after)
```

梯度下降：参数_new=参数_old-learning_rate×梯度。学习率控制调整步长；负号让参数朝局部损失下降方向移动。所有梯度先使用同一组旧参数计算完成，再更新四组参数。0.01 延续 cnn_mnist.py，是本次教学试用值，尚未证明最优。

参数更新不会自动改变先前保存的 output 或 loss，所以必须用新参数重新前向计算，再计算 loss_after。本例同一首个训练样本的损失从 0.10026332383359153 降到 0.0996374772671497；真实类别 5 的分数由 -0.0011667067253659188 变为 0.001963324357813489，但预测类别仍为 1。一次损失下降不等于预测已经正确或完整训练完成。
