## 追加代码

保留前面的演示，在文件末尾追加下面代码。循环前显式重置 h/c，确保从图片第一行重新开始。

```python
# ==================================================
# LSTM：读完整张图片并计算类别分数
# ==================================================

sequence = x_train[0]
label = y_train[0]

# 从这张图片的第一行重新开始
h = np.zeros(hidden_size)
c = np.zeros(hidden_size)

for t in range(len(sequence)):
    x = sequence[t]

    h_prev = h
    c_prev = c

    combined = np.concatenate([x, h_prev])

    f = sigmoid(np.dot(combined, W_f) + b_f)
    i_gate = sigmoid(np.dot(combined, W_i) + b_i)
    g = np.tanh(np.dot(combined, W_g) + b_g)
    o = sigmoid(np.dot(combined, W_o) + b_o)

    c = f * c_prev + i_gate * g
    h = o * np.tanh(c)

# 循环结束后，h 是最后一个时间步的隐藏状态
output = np.dot(h, W_y) + b_y
prediction = int(np.argmax(output))

print("处理的时间步数:", len(sequence))
print("最终 c:", c.shape)
print("最终 h:", h.shape)
print("最终 h 前 5 个值:", h[:5])

print("output:", output.shape)
print("10 个类别分数:", output)
print("真实标签:", label)
print("未训练时的预测类别:", prediction)
```

## 递推与共享参数

t 依次为 0～27，sequence[t] 是图片的第 t 行，尺寸 (28,)。本行输入与旧 h 拼接成 (92,)，计算三个门、候选记忆、新 c 和新 h。下一行使用这次更新后的状态。
同一张图片内部不重新清零，不重新随机初始化参数。所有 28 步共用同一组 W_f/W_i/W_g/W_o 和偏置，只有输入与状态改变。每张独立图片开始前重置状态。

循环结束的 h 是经过 28 次递推的最终隐藏状态，作为分类层输入，不保证完整保留了全部像素信息。
分类层 (64,) @ (64,10) + (10,) 得到 (10,) 原始线性分数，依次对应数字 0～9。np.argmax 返回最高分所在下标，也就是此处预测类别；它不修改或训练参数。
当前 output 不是概率，可以为负，也不要求总和等于 1。沿用手写 DNN 的线性输出教学设置，损失将在下一步实现。
