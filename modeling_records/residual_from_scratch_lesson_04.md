```python
# ==================================================
# 输出层反向传播
# ==================================================

d_output = 2 * (output - target) / 10

d_W4 = np.outer(r, d_output)
d_b4 = d_output

d_r = np.dot(d_output, W4.T)


# ==================================================
# 经过残差块末尾的 ReLU
# ==================================================

d_s = d_r * (s > 0)


# ==================================================
# 相加节点：梯度传给两条路径
# ==================================================

d_F_h = d_s.copy()
d_h_skip = d_s.copy()

print("d_W4:", d_W4.shape, "d_b4:", d_b4.shape)
print("d_r:", d_r.shape, "d_s:", d_s.shape)
print("d_F_h:", d_F_h.shape)
print("d_h_skip:", d_h_skip.shape)
```

输出层公式 output=rW4+b4，MSE 输出梯度为 2(output-target)/10。W4 梯度为 r 外积 d_output，偏置梯度相同；d_r=d_output W4^T，长度 64。

r=ReLU(s)，所以 d_s=d_r*(s>0)，掩码依据前向相加结果 s，而不是 h 或 F_h。ReLU 在零处代码约定导数为零。

相加节点 s=h+F_h 的两条输入局部导数均为 1，因此 d_F_h=d_s、直接路径贡献 d_h_skip=d_s；不除以二。copy 用于独立保存两份数组，避免后续某一分支原地修改时影响另一条。d_h_skip 只表示跳跃路径贡献，尚不是 h 的总梯度。下一步将 d_F_h 经过 W3、ReLU、W2 回传为 d_h_main，然后 d_h=d_h_skip+d_h_main。

本步实际中心差分检查 W4 全部 640 个、b4 全部 10 个、F_h 局部输入全部 64 个、h 直接路径局部输入全部 64 个梯度。检查 h 的直接路径时固定 F_h；检查 F_h 时固定 h。所有最大绝对误差低于 1e-7。未训练、未更新参数；总 h、W2/W3 和输入层梯度尚未完成。
