本步手写单张图片的前向传播，将以下代码追加到参数初始化之后。用户现有文件已包含第 2 步参数初始化；助手只读取该文件，没有修改。

```python
# ==================================================
# ReLU
# ==================================================

def relu(x):
    return np.maximum(0, x)


# ==================================================
# 单张图片的前向传播
# ==================================================

x = x_train[0]
label = y_train[0]

z1 = np.dot(x, W1) + b1
a1 = relu(z1)

output = np.dot(a1, W2) + b2

print("x:", x.shape)
print("z1:", z1.shape)
print("a1:", a1.shape)
print("output:", output.shape)

print("输出分数:", output)
print("真实标签:", label)
print("预测类别:", np.argmax(output))
```

x 为第一张图片的 784 维像素；z1 为隐藏层的 64 个加权和；a1 是 z1 经过 ReLU 后的 64 个输出；output 是输出层的 10 个分数。ReLU 将负值变为零，非负值保持，用于引入非线性。输出层本步不加 ReLU，分数允许为负；它们不是概率。np.argmax 返回最大分数所在的下标，对应类别 0～9。

公式：z1=xW1+b1；a1=max(0,z1)；output=a1W2+b2。

独立执行验证使用同一 Keras 本地缓存的第一张训练图片、除以 255 的归一化和种子 42：形状 (784,)→(64,)→(64,)→(10,)；ReLU 输出非负；所有中间值与输出均有限。真实标签 5，未训练网络预测 1。该单样本预测不用于评价训练效果。
