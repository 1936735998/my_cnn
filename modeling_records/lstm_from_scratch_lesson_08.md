# 手写 LSTM 第 8 步：末步输出门与细胞状态的梯度

日期：2026-10-06；版本：v008。
前置：用户已保存 28 步缓存、分类层梯度，d_h 是损失对最后一个隐藏状态的梯度。本步只计算末步三个局部导数。

## 追加代码

```python
# ==================================================
# 最后一个时间步：输出门与细胞状态的梯度
# ==================================================

step = cache[-1]

c_t = step["c"]
o_t = step["o"]
tanh_c = np.tanh(c_t)

# h = o * tanh(c)：传到输出门
d_o = d_h * tanh_c

# 最后一步没有来自后一时间步的细胞状态梯度
d_c_next = np.zeros(hidden_size)

# 传到当前细胞状态
d_c = d_c_next + d_h * o_t * (1 - tanh_c ** 2)

# 输出门的 sigmoid 反向传播
d_z_o = d_o * o_t * (1 - o_t)

print("d_o:", d_o.shape)
print("d_c:", d_c.shape)
print("d_z_o:", d_z_o.shape)

print("d_o 前 5 个值:", d_o[:5])
print("d_c 前 5 个值:", d_c[:5])
print("d_z_o 前 5 个值:", d_z_o[:5])
```

## 从 h 的两条输入路径反向

前向 h=o*tanh(c)，所以损失对 o 的梯度是 d_o=d_h*tanh(c)；损失经当前 h 传回 c 的贡献是 d_h*o*(1-tanh(c)²)。这里 * 为逐元素乘法，tanh 导数为 1-tanh(c)²。

c 还可通过后一时间步的细胞状态路径影响损失，因此一般需要加入 d_c_next：
d_c=d_c_next+d_h*o*(1-tanh(c)²)。
本课只处理最后一个时间步，没有后一时间步，故 d_c_next 初始化为零。后续逆序循环不能每步都清零，而要使用上一轮反向传来的 d_c*f。d_h 在更早步也将接收未来隐藏状态路径贡献，本步未实现该递推。

## 输出门激活前与激活后的梯度

输出门前向可在数学上拆成 z_o=combined W_o+b_o，o=sigmoid(z_o)。现有前向代码直接写成一行；无需改写，也无需将 z_o 保存到缓存。
sigmoid 导数为 o*(1-o)，所以 d_z_o=d_o*o*(1-o)。
d_o 是对输出门值 o 的梯度，d_z_o 是对激活前线性输入 z_o 的梯度。两者同形状、不同含义；后续用 d_z_o 计算 W_o/b_o 梯度和传回 combined。d_c 是对状态的导数，不是对 c 的直接更新量。
