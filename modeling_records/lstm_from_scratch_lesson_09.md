# 手写 LSTM 第 9 步：遗忘门、输入门与候选记忆的梯度

日期：2026-10-06；版本：v009。
前置：用户已完成第 8 步，step=cache[-1]，d_c 是末时间步细胞状态梯度。这里只继续求该时刻的局部导数。

## 追加代码

```python
# ==================================================
# 最后一个时间步：遗忘门、输入门与候选记忆的梯度
# ==================================================

f_t = step["f"]
i_t = step["i_gate"]
g_t = step["g"]
c_prev_t = step["c_prev"]

# c = f * c_prev + i * g：分别传回三个分支
d_f = d_c * c_prev_t
d_i = d_c * g_t
d_g = d_c * i_t

# 继续传过 sigmoid 和 tanh
d_z_f = d_f * f_t * (1 - f_t)
d_z_i = d_i * i_t * (1 - i_t)
d_z_g = d_g * (1 - g_t ** 2)

print("d_f:", d_f.shape)
print("d_i:", d_i.shape)
print("d_g:", d_g.shape)

print("d_z_f:", d_z_f.shape)
print("d_z_i:", d_z_i.shape)
print("d_z_g:", d_z_g.shape)

print("d_z_f 前 5 个值:", d_z_f[:5])
print("d_z_i 前 5 个值:", d_z_i[:5])
print("d_z_g 前 5 个值:", d_z_g[:5])
```

## 对乘法分支求导

前向 c=f*c_prev+i*g，全部是对应位置乘法。
对 f 求导时，c_prev 是系数，所以 d_f=d_c*c_prev。
对 i 求导时，g 是系数，所以 d_i=d_c*g。
对 g 求导时，i 是系数，所以 d_g=d_c*i。
每次求导固定其他输入，沿当前分支乘链式法则系数；相加节点将同一 d_c 传给两个相加分支。

## 继续通过激活函数

遗忘门和输入门使用 sigmoid：导数为激活值乘 (1-激活值)。
候选记忆使用 tanh：导数为 1-候选值²。
因此 d_z_f/d_z_i/d_z_g 按代码计算，无需再计算或缓存 z 的数值。
d_f/d_i/d_g 是对门值或候选记忆值的梯度，后三者是对激活前线性输入的梯度，均尚不是权重或偏置梯度。
